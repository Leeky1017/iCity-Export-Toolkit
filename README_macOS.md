# macOS 使用说明

需要 Python 3.10 或更新版本。下载并解压整个仓库，保留两个 `.py` 文件在同一目录。在终端进入该目录后运行：

```bash
python3 icity_export.py
```

首次运行会自动准备本地依赖，然后询问账号、隐藏输入的密码、导出目录和文件名前缀。默认通过手机端认证接口读取自己的普通和封存日记，无需另找用户 ID。

结果包括 JSON、TXT、按日期拆分的 Markdown、原始分页和核对报告。**图片只保留链接和元数据，没有下载原图。** 窗口显示的是按 ID 去重后的实际读取数，不是重复请求的累加值。

只有服务器明确结束、条数通过核对且阅读文件全部生成后，`.report.json` 才会显示 `complete`。中断和错误会保留已读内容，此版本不自动跨运行续传。已有同名结果时默认不覆盖；请换前缀或目录。

不要把密码写进命令，不要把输出目录或登录凭据上传 GitHub。其他参数见 [README](README.md)。
