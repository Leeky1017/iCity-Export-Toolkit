# Windows 使用说明

1. 安装 Python 3.10 或更新版本。打开 PowerShell，运行 `py --version` 确认。
2. 下载并解压整个仓库，不要只保存单个脚本。`icity_export.py` 与 `icity_native.py` 必须在同一文件夹。
3. 在该文件夹打开 PowerShell，运行：

```powershell
py icity_export.py
```

首次运行会自动创建 `.icity_export_venv` 并安装依赖。随后输入 iCity 用户名或邮箱、密码、输出位置和文件名前缀。密码不会显示字符；这是正常的。默认会从登录响应识别自己的用户 ID。

默认读取普通和封存日记。照片只保存链接与元数据，不下载原图。导出的 TXT 可直接阅读，Markdown 按日期拆分，JSON 和原始分页用于后续处理与核验。

不要仅凭窗口中的累计条数认定完整。程序会在完成时核对数量，详情保存在 `.report.json`。遇到中断或网络错误会保留已读取内容；保留整个输出文件夹。此版本不会跨运行自动续传。

如果已有同名结果，请换个前缀或输出目录，避免覆盖。`--overwrite` 是明确允许替换，旧原始分页会另外保留。不要把密码放进命令，也不要把日记或登录凭据上传 GitHub。

更多选项及退出码见 [README](README.md)。
